# Neverness to Everness Einrichtungsanleitung

Erfahre, wie du `.ueformat`-Charaktermodelle aus Neverness to Everness importierst, Omatsuri-Shader zuweist und Post-Processing-Compositor-Nodes konfigurierst.

## Schnelle Schritte

1. Installiere das mitgelieferte **UEFormat**-Add-on (wird automatisch von Gacha Setup übernommen).
2. Öffne den **Character Setup Wizard** (<kbd>N</kbd>-Taste).
3. Wähle **Neverness to Everness**.
4. Klicke auf **Import & Setup NTE Model**.
