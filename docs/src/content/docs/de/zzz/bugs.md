# ZZZ Fehler & Lösungen

Detaillierte Anleitung zur Diagnose und Behebung häufiger Probleme mit Zenless Zone Zero-Modellen.

## Häufige Probleme

### Problem 1: Schulter-Widget-Roll-Rotation umgekehrt
- **Symptom**: Schulter-Steuerungs-Bones drehen sich rückwärts, wenn die Arme bewegt werden.
- **Lösung**: Nutze das Tool **Correct Shoulder Roll** unter den ZZZ Rig Utilities.

### Problem 2: Versatz der Oberschenkel-Parent-Steuerung
- **Symptom**: Bein-Meshes lösen sich ab oder dehnen sich unnatürlich beim Beugen der Hüfte.
- **Lösung**: Klicke im N-Panel des Add-ons auf **Reposition Thigh Parents**.
