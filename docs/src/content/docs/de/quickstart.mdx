## Installationsschritte

1. Lade die neueste `Gacha_Setup-<version>.zip` aus dem [aktuellen GitHub-Release](https://github.com/PaoloESAN/gacha-setup/releases/latest) herunter.
2. Starte Blender 5.2 (empfohlen) oder Blender/Goo Engine 4.1+. Bei Blender-Versionen unter 4.5 installiere zuerst BetterFBX.
3. Ziehe die heruntergeladene `.zip`-Datei per Drag-and-drop in das Blender-Fenster.
4. Aktiviere das Kontrollkästchen **Enable Add-on** und klicke zur Bestätigung auf **OK**.
5. Falls es nicht automatisch installiert wird, öffne **Edit > Preferences > Add-ons**, klicke auf **Install from Disk...**, wähle die `.zip`-Datei aus und aktiviere das Kontrollkästchen des Add-ons.

## Setup Character

1. Drücke `N` im 3D Viewport und öffne den Seitenleisten-Tab **Gacha Setup** (**Character Setup Wizard**-Panel).

<Image src={entireSetupImg} alt="Gacha Setup Hauptpanel" loading="eager" />

2. Wähle dein Spiel aus.

<Image src={selectGameImg} alt="Dropdown-Menü Select Game" loading="lazy" />

3. Klicke auf **Setup Character**.

4. Wähle deinen [Charakterordner](/de/character-models/) aus, konfiguriere optional die **Setup Settings** in der Seitenleiste des Dateibrowsers (**Shader**, **Disable Rigging**, **Hair & Clothes Physics**) und klicke auf **Select Character Folder** (oder wähle die zugehörige `.zip`- / `.7z`-Datei aus).

<Image src={selectCharacter} alt="Select Character Folder" loading="lazy" />

5. Warte ein paar Sekunden, bis dein Charakter fertig in der Szene erscheint.

<Image src={characterEscene} alt="Charakter fertig in der Szene (Einrichtung erfolgreich abgeschlossen)" loading="lazy" />
