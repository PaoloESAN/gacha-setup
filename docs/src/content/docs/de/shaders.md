# Shader- & Material-Pipeline

Gacha Setup verknüpft und konfiguriert automatisch benutzerdefinierte Anime-Shader für jede Spiel-Engine-Pipeline.

## Funktionen

- **Automatisiertes Textur-Mapping**: Diffuse-, Lightmap-, Normal- und Shadow-Maps werden automatisch verbunden.
- **Benutzerdefinierte Inverted-Hull-Outlines**: Präzise Anpassung von Outline-Dicke und -Farbe.
- **Augenschatten- & Gesichtskorrekturen**: Shader-Nodes zur Vermeidung unerwünschter Schattenwürfe auf den Augen.
