## Sparxie Hoyotoon

Beim Herunterladen der Modell-Assets von Sparxie über **HoyoToon** können Texturprobleme auftreten, wenn du die Variante **Elation** auswählst.

### Lösung

- Achte darauf, die Outfit-Variante **Candy-Coated Waves** anstelle von **Elation** zu verwenden.
- **Hinweis**: Dies verändert das Modell in keiner Weise; es behebt lediglich die Texturprobleme.
