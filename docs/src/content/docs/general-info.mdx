2. **Character Setup Wizard**: Select your game (Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Neverness to Everness, Wuthering Waves, Arknights: Endfield), click **Run Entire Setup** to execute the complete automated import, shaders, outlines, rigging, and compositing pipeline in one click, and adjust **Setup Settings** beforehand (**Hair & Clothes Physics** for dynamic Damped Track physics, **Disable Rigging** to skip rig and facial rig generation).
3. **Utilities**: Extra helper operators, such as **Jideeh's Camera**.
4. **Old Setup**: Legacy step-by-step sections (Basic / Advanced Setup) to run each setup stage individually from top to bottom (only for advanced users).

## Character Settings (Item Panel)

Once your character is set up, select the character armature or mesh and press `N` in the 3D Viewport. Open the **Item** tab to access the **Character Settings** panel, with real-time controls that vary slightly per game (no need to edit shader node trees manually):

- **Lighting Mode**: Switch between built-in lighting presets — `Default`, `Sunrise`, `Day`, `Sunset`, `Night`, `Rainy` — or choose `Custom` to fine-tune each color channel of the shader.
- **Hair & Clothes Physics**: Apply or adjust the dynamic Damped Track physics on hair and clothing.
- **Rig Layers**: Organized bone collections (Face, Torso, Arms, Legs, Fingers, Hair, Clothes, Lighting, and more) to isolate body parts while animating.
- **Light direction object**: A dedicated object is created in the scene collection to rotate the light vector (adjust its **Rotation** XYZ values in the Item Transform panel).

For the exact options of each game, see its **Lights & Coloramp** guide:

- [Genshin Impact](/genshin/lights-coloramp/)
- [Honkai: Star Rail](/hsr/lights-coloramp/)
- [Zenless Zone Zero](/zzz/lights-coloramp/)
- [Neverness to Everness](/nte/lights-coloramp/)
- [Wuthering Waves](/wuwa/lights-coloramp/)
