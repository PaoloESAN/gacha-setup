# Neverness to Everness Setup Guide

Learn how to import `.ueformat` character models from Neverness to Everness, assign Omatsuri shaders, and configure post-processing compositor nodes.

## Quick Steps

1. Install the bundled **UEFormat** addon (automatically handled by Gacha Setup).
2. Open **Character Setup Wizard** (<kbd>N</kbd> key).
3. Select **Neverness to Everness**.
4. Click **Import & Setup NTE Model**.
