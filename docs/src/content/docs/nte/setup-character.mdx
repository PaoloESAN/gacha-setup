## 1. Opening the Setup Wizard

1. Press `N` in the 3D Viewport to open the sidebar.
2. Navigate to the **Character Setup Wizard** tab.
3. In the **Game** drop-down menu, select **Neverness to Everness**.

<Image src={ntePanel} alt="Neverness to Everness Setup Wizard N-Panel" loading="eager" />

---

## 2. Importing Your Character

You can set up your model in one click using **Run Entire Setup** or step-by-step via **Basic Setup**.

1. Click **Run Entire Setup** (or **Set Up Character** under Basic Setup).
2. A file browser window will appear. Navigate to your [character folder](/character-models/#nte) containing the `.fbx` model and textures.
3. Click **Select NTE Character**.

<Image src={nteCharacter} alt="Blender File View selecting NTE character model folder" loading="lazy" />

:::note
The import process may take a long time to complete.
:::

---

## 3. Automated Basic Setup Pipeline

When running the setup, the add-on executes the following automated steps for Neverness to Everness:

- **Set Up Character**: Imports the `.fbx` mesh, cleans vertex groups, and standardizes bone hierarchies.
- **Set Up Materials**: Replaces default Blender materials with custom **NTE Toon Shader** nodes, binding diffuse, lightmap, and color ramp textures.
- **Set Up Outlines**: Applies geometry-node inverted-hull outline modifiers to all character meshes for crisp line art rendering.
- **Fix Transformations**: Resets location, rotation, and scale transformations while linking facial drivers to light vectors.
- **Rig Character**: Configures control shapes and facial bone drivers.
- **Finish Setup**: Switches Color Management to **Standard** to preserve raw texture color accuracy.

## 4. Viewport Shading & Compositor Settings

To display NTE toon shaders and real-time head shadow compositing in the viewport:

1. Enter the **Compositing** workspace from the top menu bar in Blender.

<Image src={nteComp1} alt="Entering Compositing workspace from top menu bar in Blender" loading="lazy" />

2. Move the **Alpha** node to disconnect it from **Group Output** and **Viewer**, and connect the **Mix** node output directly into **Group Output** and **Viewer**.

<Image src={nteComp2} alt="Disconnecting Alpha node and connecting Mix node to Group Output and Viewer" loading="lazy" />

3. Return to the **Layout** workspace in the top bar, open the **Viewport Shading** menu, and set **Compositor** to **Always** (or **Camera**).

<Image src={nteComp3} alt="Switching back to Layout workspace and setting Viewport Shading Compositor to Always" loading="lazy" />
