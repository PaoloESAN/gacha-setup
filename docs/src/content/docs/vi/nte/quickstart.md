# Hướng dẫn thiết lập Neverness to Everness

Tìm hiểu cách nhập các mô hình nhân vật `.ueformat` từ Neverness to Everness, gán shader Omatsuri và cấu hình các node compositor hậu kỳ.

## Các bước nhanh

1. Cài đặt add-on **UEFormat** đi kèm (được Gacha Setup tự động xử lý).
2. Mở **Character Setup Wizard** (phím <kbd>N</kbd>).
3. Chọn **Neverness to Everness**.
4. Nhấp **Import & Setup NTE Model**.
