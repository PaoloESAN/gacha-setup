# Visión General del Rigging

El módulo de rigging de **Gacha Setup** unifica la corrección de jerarquía de huesos, la creación de drivers faciales, el manejo de colecciones de huesos y la generación de rgs Rigify para modelos gacha anime.

## Características Principales de Rigging

1. **Colecciones de Huesos para Blender 5.2+**:
   - Interfaz de **Capas de Rig** interactiva en el panel N con conmutadores de visibilidad y botones favoritos ($\star$).
   - Búsqueda dinámica de colecciones para prevenir errores de script de armadura en Blender 5.x.

2. **Integración con Expy-Kit y Rigify**:
   - Alineación de metarig y generación de controles de Rigify en un solo clic.
   - Re-emparentado automático de ropa, accesorios y mallas de cabello.

3. **Pipeline de Drivers Faciales**:
   - Controles de seguimiento ocular enlazados con drivers de ubicación Y para evitar que los ojos sobresalgan.
   - Shape keys de expresión vinculados a gizmos faciales principales.
