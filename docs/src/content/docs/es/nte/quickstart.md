# Guía de Configuración de Neverness to Everness

Aprende a importar modelos `.ueformat` de Neverness to Everness, asignar shaders de Omatsuri y configurar los nodos del compositor para post-procesado.

## Pasos Rápidos

1. Verifica que la dependencia **UEFormat** esté activa (se instala automáticamente).
2. Despliega el panel **Character Setup Wizard** (tecla <kbd>N</kbd>).
3. Selecciona **Neverness to Everness**.
4. Haz clic en **Importar y Configurar Modelo NTE**.
