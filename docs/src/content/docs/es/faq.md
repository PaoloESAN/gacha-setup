# Preguntas Frecuentes

### ¿Qué versiones de Blender son compatibles?
**Blender 5.2+ oficial**. Se recomienda encarecidamente utilizar las versiones oficiales estándar.

### ¿Funciona con Rigify?
¡Sí! El add-on integra ExpyKit para automatizar la generación de rigs compatibles con Rigify.
