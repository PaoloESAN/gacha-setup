## Sparxie Hoyotoon

Al descargar los assets del modelo de Sparxie desde **HoyoToon**, pueden presentarse problemas con las texturas si se utiliza la variante **Elation**.

### Solución

- Se debe usar la variante de atuendo **Candy-Coated Waves** en lugar de **Elation**.
- **Nota**: Esto no cambia en nada el modelo 3D, solo arregla los problemas con las texturas.
