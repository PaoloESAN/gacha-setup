:::note
Gacha Blender Setup está diseñado para **Blender 5.2+**. Versiones anteriores de Blender o Goo Blender no están soportadas.
:::

## Instalación y Configuración

1. Descarga el paquete de lanzamiento más reciente `Gacha_Blender_Setup-<version>.zip` desde GitHub Releases.
2. Inicia **Blender 5.2+**.
3. Abre **Editar > Preferencias > Add-ons**.
4. Haz clic en **Instalar desde disco...** en la esquina superior derecha.
5. Selecciona el archivo `.zip` descargado y activa la casilla del add-on.
6. Presiona `N` en la Vista 3D para abrir el panel lateral **Character Setup Wizard**.
