# Bugs y Soluciones de Zenless Zone Zero

Guía detallada para diagnosticar y corregir problemas comunes en modelos de Zenless Zone Zero.

## Problemas Comunes

### Problema 1: Rotación Invertida en Widgets de Hombros
- **Síntoma**: Los huesos de control del hombro rotan hacia atrás al mover los brazos.
- **Solución**: Utiliza la herramienta **Correct Shoulder Roll** dentro de las utilidades de rig de ZZZ.

### Problema 2: Desplazamiento del Padre del Muslo
- **Síntoma**: Las mallas de las piernas se desprenden o se estiran al doblar las caderas.
- **Solución**: Haz clic en **Reposition Thigh Parents** en el panel N de la extensión.
