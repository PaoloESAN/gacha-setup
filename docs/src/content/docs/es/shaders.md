# Pipeline de Shaders y Materiales

Gacha Blender Setup vincula y configura automáticamente shaders anime personalizados adaptados al pipeline de cada juego.

## Características

- **Mapeo Automatizado de Texturas**: Conexión automática de mapas Diffuse, Lightmap, Normal y Shadow.
- **Outlines Personalizados (Inverted Hull)**: Ajuste preciso del grosor y color de la línea de delineado.
- **Sombra de Ojos y Corrección Facial**: Nodos de shader diseñados para prevenir sombras indeseadas sobre los ojos.
