## Características Principales

- **Nativo para Blender 5.2+**: API de Python actualizada, interfaz de Capas de Rig en el panel N interactiva con botones de favoritos.
- **Rigging Automatizado**: Integración de Rigify y ExpyKit sin necesidad de configuración manual.
- **Suite de Shaders y Materiales**: Enlazado automático de texturas, solución de delineados y sombra de ojos.
- **i18n y Chibis Interactivos**: Documentación multi-idioma con asistentes flotantes estilo gacha para cada juego.
