# Genshin Impact Character Setup

Learn how to import, rig, and apply Festivity shaders to Genshin Impact characters using **Gacha Blender Setup**.

## Quick Steps

1. Import your Genshin model (`.fbx` or `.pmx`) into Blender 5.2+.
2. Open the **Character Setup Wizard** panel (<kbd>N</kbd> key).
3. Select **Genshin Impact** as the target game.
4. Click **Automated Character Setup**.
