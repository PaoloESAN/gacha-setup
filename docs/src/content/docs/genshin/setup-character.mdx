## 1. Opening the Setup Wizard

1. Press `N` in the 3D Viewport to open the sidebar.
2. Navigate to the **Character Setup Wizard** tab.
3. In the **Game** drop-down menu, select **Genshin Impact**.

<Image src={genshinPanel} alt="Genshin Impact Setup Wizard N-Panel" loading="eager" />

---

## 2. Importing Your Character

You can set up your model in one click using **Run Entire Setup** or step-by-step via **Basic Setup**.

1. Click **Run Entire Setup** (or **Set Up Character** under Basic Setup).
2. A file browser window will appear. Navigate to your [character folder](/character-models/#genshin) containing the `.fbx` model and textures (such as `Avatar_Girl_Catalyst_Charlotte.fbx`).
3. Click **Select Character Folder**.

<Image src={genshinCharacter} alt="Blender File View selecting character model folder" loading="lazy" />

## 3. Automated Basic Setup Pipeline

When running the setup, the add-on executes the following automated steps:

- **Set Up Character**: Imports the `.fbx` mesh, cleans vertex groups, and standardizes bone hierarchies.
- **Set Up Materials**: Replaces default Blender materials with custom **Festivity Toon Shader** nodes, automatically binding diffuse (`_fuse`), lightmap (`_map`), and color ramp (`_amp`) textures.
- **Set Up Outlines**: Applies geometry-node inverted-hull outline modifiers to all character meshes for crisp line art rendering.
- **Fix Transformations**: Resets location, rotation, and scale transformations while linking facial drivers to light vectors.
- **Rig Character**: Configures control shapes and facial bone drivers.
- **Finish Setup**: Switches Color Management to **Standard** to preserve raw texture color accuracy.

## 4. Viewport Shading & Compositor Settings

To view Festivity shaders and real-time head shadow compositing in the viewport:

1. Open the **Viewport Shading** menu (top right of the 3D Viewport).
2. Under **Lighting**, enable **Scene Lights** and **Scene World**.
3. Under **Compositor**, set the dropdown mode to **Always** (or **Camera**).
