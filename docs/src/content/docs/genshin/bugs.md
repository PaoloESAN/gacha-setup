# Genshin Impact Bugs & Fixes

This page documents common issues when importing and rigging Genshin Impact models, along with exact step-by-step solutions.

## Common Issues

### Issue 1: Eyes Shadow Clipping
- **Symptom**: Dark shadows casting across eye meshes when moving lights.
- **Solution**: Run **Fix Eyeshadow Material** in the setup panel or toggle the custom eye material group.

### Issue 2: Outline Line Thickness Scaling
- **Symptom**: Inverted-hull outlines appear too thick or distorted in Blender 5.2+.
- **Solution**: Use the **Outline Thickness Modifier** tool in the N-panel to scale stroke offset dynamically.
