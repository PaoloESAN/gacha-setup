# ZZZ Bugs & Solutions

Detailed walkthrough for diagnosing and fixing common issues with Zenless Zone Zero models.

## Common Issues

### Issue 1: Shoulder Widget Roll Rotation Flipped
- **Symptom**: Shoulder control bones rotate backwards when moving arms.
- **Solution**: Use the **Correct Shoulder Roll** tool under ZZZ Rig Utilities.

### Issue 2: Thigh Parent Control Offset
- **Symptom**: Leg meshes detach or stretch abnormally when bending the hips.
- **Solution**: Click **Reposition Thigh Parents** in the addon N-panel.
