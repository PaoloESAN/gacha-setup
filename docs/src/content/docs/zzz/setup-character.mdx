## 1. Opening the Setup Wizard & Shader Selection

1. Press `N` in the 3D Viewport to open the sidebar.
2. Navigate to the **Character Setup Wizard** tab.
3. In the **Game** drop-down menu, select **Zenless Zone Zero**.
4. Under **Setup Settings**, select your preferred **Shader**:
   - **Kythera's Shader** (Recommended): Modern anime shader supporting real-time Lighting Mode presets, rim lighting, fake SSS, and tint controls in the Item panel.
   - **Legacy Shader**: Classic ZZZ Setup File V2.0 shader with 3D viewport control rig boards.

## 2. Importing Your Character

You can set up your model in one click using **Run Entire Setup** or step-by-step via **Basic Setup**.

1. *(Optional)* Under **Setup Settings**, enable **Hair & Clothes Physics** to add dynamic physics to the hair and clothing when the character moves, and adjust the influence sliders if desired.
2. Click **Run Entire Setup** (or **Set Up Character** under Basic Setup).
3. A file browser window will appear. Navigate to your [character folder](/character-models/#zzz) containing the `.fbx` model and textures.
4. Click **Select Character Folder**.

## 3. Automated Basic Setup Pipeline

When running the setup, the add-on executes the following automated steps for Zenless Zone Zero:

- **Set Up Character**: Imports the `.fbx` mesh, cleans vertex groups, and standardizes bone hierarchies.
- **Set Up Materials**: Replaces default Blender materials with your chosen **ZZZ Toon Shader** nodes, automatically binding diffuse, lightmap, eyeshadow, and color ramp textures.
- **Set Up Outlines**: Applies geometry-node inverted-hull outline modifiers to all character meshes for crisp line art rendering.
- **Fix Transformations**: Resets location, rotation, and scale transformations.
- **Rig Character**: Integrates the specialized **jideeh ZZZ Face Rig** and configures breast/torso physics controls.
- **Finish Setup**: Switches Color Management to **Standard** to preserve raw texture color accuracy.

## 4. Optional: Adding Eyeshadow Material

If your character requires manual eyeshadow material assignment:

1. Select the character's face mesh and press `Tab` to enter **Edit Mode**.
2. Hover over the eyeshadow geometry and press `L` to select the eyeshadow mesh components.
3. In the **Material Properties** tab, click the `+` button to create a new material slot.

<Image src={zzzEyeshadow1} alt="Selecting eyeshadow mesh in Edit Mode and adding a new material slot" loading="lazy" />

4. Assign the **ZZZ Shader Eye** material to the newly created slot.

<Image src={zzzEyeshadow2} alt="Assigning ZZZ Shader Eye material to slot" loading="lazy" />

5. Click the **Assign** button to apply the material to the selected eyeshadow mesh.

<Image src={zzzEyeshadow3} alt="Clicking Assign button to apply eyeshadow material" loading="lazy" />
