# Zenless Zone Zero Setup Guide

Learn how to automate ZZZ model importing, specialized jideeh face rigs, custom breast/breath physics controls, and light collection setup.

## Quick Steps

1. Import your ZZZ model into Blender 5.2+.
2. Open the **Character Setup Wizard** (<kbd>N</kbd> panel).
3. Choose **Zenless Zone Zero** in the game selection dropdown.
4. Click **Run ZZZ Character Setup**.
