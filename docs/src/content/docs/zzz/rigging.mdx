## 1. Jideeh Facerig

Upon importing and setting up a Zenless Zone Zero character, the add-on configures the **jideeh ZZZ Face Rig** integrated directly inside the character's main armature for advanced facial expression control.

<Image src={zzzFacerig} alt="jideeh ZZZ Face Rig 3D control board and character rig" loading="eager" />

### Key Facial Controls & Features

- **jideeh Facial Rig Integration**: Advanced drivers for eyebrows, eyelids, eye tracking, and mouth shape keys.
- **On-Face Control Widgets**: Allows intuitive posing of individual facial features directly in the 3D viewport.
