## 1. Opening the Setup Wizard

1. Press `N` in the 3D Viewport to open the sidebar.
2. Navigate to the **Character Setup Wizard** tab.
3. In the **Game** drop-down menu, select **Honkai: Star Rail**.

<Image src={hsrPanel} alt="Honkai: Star Rail Setup Wizard N-Panel" loading="eager" />

---

## 2. Importing Your Character

You can set up your model in one click using **Run Entire Setup** or step-by-step via **Basic Setup**.

1. *(Optional)* Under **Setup Settings**, enable **Hair & Clothes Physics** to add dynamic physics to the hair and clothing when the character moves, and adjust the influence sliders if desired.
2. Click **Run Entire Setup** (or **Set Up Character** under Basic Setup).
3. A file browser window will appear. Navigate to your [character folder](/character-models/#hsr) containing the `.fbx` model and textures (such as `Avatar_Girl_March7th.fbx`).
4. Click **Select Character Folder**.

<Image src={hsrCharacter} alt="Blender File View selecting HSR character model folder" loading="lazy" />

## 3. Automated Basic Setup Pipeline

When running the setup, the add-on executes the following automated steps:

- **Set Up Character**: Imports the `.fbx` mesh, cleans vertex groups, and standardizes bone hierarchies for Honkai: Star Rail.
- **Set Up Materials**: Replaces default Blender materials with custom **StellarToon Shader** nodes, automatically binding diffuse (`_fuse`), lightmap (`_map`), and color ramp (`_amp`) textures.
- **Set Up Outlines**: Applies geometry-node inverted-hull outline modifiers to all character meshes for crisp line art rendering.
- **Fix Transformations**: Resets location, rotation, and scale transformations.
- **Rig Character**: Integrates the **Isaac Face Rig** and configures eye Y-drivers to prevent pupil displacement during blink or shape key animations.
- **Finish Setup**: Switches Color Management to **Standard** to preserve raw texture color accuracy.
