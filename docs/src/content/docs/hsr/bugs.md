# HSR Bugs & Solutions

Detailed guide on diagnosing and repairing common armature, eye tracking, and shader issues on Honkai: Star Rail characters.

## Known Issues

### Issue 1: Eye Popping During Shape Key Expressions
- **Symptom**: Pupil mesh dislocates from the eyeball socket when applying facial shape keys.
- **Solution**: Run **Re-bind HSR Eye Drivers** from the setup wizard to attach Y-location driver constraints.

### Issue 2: Finger Rotation Axis Misalignment
- **Symptom**: Finger bones bend in unnatural angles during pose mode.
- **Solution**: Click **Recalculate HSR Bone Roll** in the rigging utilities tab.
