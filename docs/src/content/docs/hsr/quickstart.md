# Honkai: Star Rail Setup Guide

Automate Star Rail character imports, StellarToon shaders, Isaac facial rigs, and eye drivers in Blender 5.2+.

## Quick Steps

1. Import your HSR character model into Blender 5.2+.
2. Open the **Character Setup Wizard** (<kbd>N</kbd> key).
3. Select **Honkai: Star Rail** in the game selection dropdown.
4. Click **Apply HSR Pipeline**.
