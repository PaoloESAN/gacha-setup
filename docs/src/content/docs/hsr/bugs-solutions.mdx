## Sparxie Hoyotoon

When downloading Sparxie's model assets from **HoyoToon**, you may encounter texture issues if selecting the **Elation** variant.

### Solution

- Make sure to use the **Candy-Coated Waves** outfit variant instead of **Elation**.
- **Note**: This does not change the model in any way; it solely fixes the texture issues.
