## 1. Membuka Wizard Penyiapan

1. Tekan `N` di 3D Viewport untuk membuka bilah samping.
2. Buka tab **Character Setup Wizard**.
3. Pada menu tarik-turun **Game**, pilih **Arknights: Endfield**.

<Image src={akePanel} alt="Panel N wizard penyiapan Arknights: Endfield (v3.7.1)" loading="eager" />

---

## 2. Mengimpor Karakter

Anda dapat menyiapkan model dengan satu klik menggunakan **Run Entire Setup**, atau langkah demi langkah melalui **Old Setup**.

1. *(Opsional)* Di **Setup Settings**, aktifkan **Hair & Clothes Physics** untuk menambahkan fisika dinamis pada rambut dan pakaian. Aktifkan **Disable Rigging** untuk melewati pembuatan rig dan hanya mengimpor material serta garis tepi.
2. Klik **Run Entire Setup** (atau **Set Up Character** pada Old Setup).
3. Jendela penelusuran berkas akan terbuka. Buka [folder karakter](/id/character-models/#ake---arknights-endfield) yang berisi model `.fbx` (`chr_XXXX_name_uimodel.fbx`, misalnya `chr_0032_lizhiyan_uimodel.fbx`), subfolder `Materials`, dan tekstur.
4. Klik **Select Character Folder**.

<Image src={akeCharacter} alt="Memilih folder model karakter Arknights: Endfield di Blender File View" loading="lazy" />

---

## 3. Alur Penyiapan Otomatis

Saat penyiapan dijalankan, add-on melakukan langkah-langkah otomatis berikut untuk Arknights: Endfield:

- **Set Up Character**: Mengimpor mesh `.fbx`, membersihkan vertex group, dan menstandarkan hierarki tulang.
- **Set Up Materials**: Mengganti material bawaan Blender dengan node shader **Arknights: Endfield PBRToon** khusus (`Arknights: Endfield_PBRToonBase`, `BaseFace`, `BaseHair`) dan menghubungkan material tubuh, pakaian, wajah, rambut, iris, serta alfa.
- **Setup Outlines**: Menerapkan modifier garis tepi inverted-hull (`Dots Stroke`) pada semua mesh karakter untuk menghasilkan garis yang tegas.
- **Rig Character**: Mengonfigurasi armature Rigify, adaptasi **Isaac Face Rig** untuk Endfield, dan sistem driver kepala.
- **Setup Compositor Nodes**: Mengonfigurasi susunan node compositing untuk merender bayangan kepala secara langsung.
- **Finish Setup**: Mengganti Color Management ke **Standard** untuk menjaga akurasi warna asli tekstur.

## 4. Pengaturan Viewport Shading dan Compositor

Untuk menampilkan shader PBRToon dan compositing bayangan kepala secara langsung di viewport:

1. Buka menu **Viewport Shading** di pojok kanan atas 3D Viewport.
2. Pada bagian **Lighting**, aktifkan **Scene Lights** dan **Scene World**.
3. Pada bagian **Compositor**, pilih mode **Always** (atau **Camera**).
