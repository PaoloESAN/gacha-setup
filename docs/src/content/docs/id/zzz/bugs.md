# Masalah dan Solusi ZZZ

Panduan terperinci untuk mendiagnosis dan memperbaiki masalah umum pada model Zenless Zone Zero.

## Masalah Umum

### Masalah 1: Rotasi Roll Widget Bahu Terbalik
- **Gejala**: Tulang pengontrol bahu berputar ke arah sebaliknya saat lengan digerakkan.
- **Solusi**: Gunakan alat **Correct Shoulder Roll** pada ZZZ Rig Utilities.

### Masalah 2: Pergeseran Pengontrol Induk Paha
- **Gejala**: Mesh kaki terlepas atau meregang secara tidak normal saat pinggul ditekuk.
- **Solusi**: Klik **Reposition Thigh Parents** pada panel N add-on.
