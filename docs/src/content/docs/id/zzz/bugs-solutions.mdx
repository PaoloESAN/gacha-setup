### Solusi Langkah demi Langkah

1. Pilih mesh wajah karakter, lalu tekan `Tab` untuk masuk ke **Edit Mode**.
2. Arahkan kursor ke geometri bayangan mata, lalu tekan `L` untuk memilih komponen mesh bayangan mata.
3. Pada tab **Material Properties**, klik tombol `+` untuk membuat slot material baru.

<Image src={zzzEyeshadow1} alt="Memilih mesh bayangan mata dalam Edit Mode dan menambahkan slot material baru" loading="lazy" />

4. Pilih material **ZZZ Shader Eye** untuk slot yang baru dibuat.

<Image src={zzzEyeshadow2} alt="Menetapkan material ZZZ Shader Eye pada slot" loading="lazy" />

5. Klik tombol **Assign** untuk menerapkan material pada mesh bayangan mata yang dipilih.

<Image src={zzzEyeshadow3} alt="Mengklik tombol Assign untuk menerapkan material bayangan mata" loading="lazy" />
