## 1. Mengatur Arah Cahaya dan Bayangan

Selama penyiapan karakter, objek khusus `Light Direction_<Character>` dibuat dalam koleksi adegan.

1. Temukan `Light Direction_<Character>` pada panel **Outliner**.
2. Buka panel **Item Transform** pada Object Properties.
3. Sesuaikan nilai **Rotation** (XYZ Euler) untuk memutar vektor cahaya:
   - **Rotation Z**: Memutar sudut matahari secara horizontal mengelilingi karakter.
   - **Rotation Y**: Menyesuaikan kemiringan horizontal cahaya pada karakter.
   - **Rotation X**: Menyesuaikan kemiringan vertikal garis bayangan.

## 2. Shader Kythera: Pengaturan Karakter (Panel Item)

Saat menggunakan **Kythera's Shader**, pilih karakter dan buka tab **Item** di bilah samping 3D Viewport (tombol `N`) untuk mengakses kontrol shader secara langsung.

### Mode dan Preset Pencahayaan

Pilih preset pencahayaan lingkungan atau beralih ke mode Custom:

- **Default**: Tampilan standar gim.
- **Sunrise**: Cahaya pagi lembut dengan bayangan pastel.
- **Day**: Pencahayaan siang yang tegas.
- **Sunset**: Nuansa senja keemasan yang hangat.
- **Night**: Palet cahaya bulan yang redup.
- **Rainy**: Pencahayaan mendung yang menyebar.
- **Custom**: Membuka pengaturan terperinci untuk warna, bayangan, dan cahaya tepi.

<Image src={zzzLight1} alt="Preset Lighting Mode shader Kythera di Zenless Zone Zero" loading="lazy" />

### Shading dan Warna (Mode Custom)

Saat diatur ke **Custom**, Anda dapat menyesuaikan:

- **Ambient**: Warna dasar cahaya ambien.
- **Lit Tint / Lit Brightness**: Warna cahaya langsung dan tingkat kecerahannya.
- **Shadow Tint / Shadow Intensity**: Warna bayangan cel dan tingkat kegelapannya.
- **Fake SSS Intensity**: Menyesuaikan simulasi peredupan lembut Subsurface Scattering (SSS) pada kulit dan kain.

<Image src={zzzLight2} alt="Pengaturan shading dan warna pada Character Settings ZZZ" loading="lazy" />

### Pengaturan Cahaya Tepi

Sesuaikan efek sorotan tepi di sekeliling karakter:

- **Enable Rim Light**: Mengaktifkan atau menonaktifkan efek cahaya tepi.
- **Color**: Warna kilau cahaya tepi.
- **Coverage**: Seberapa jauh cahaya tepi menyebar pada siluet mesh.
- **Brightness**: Intensitas cahaya tepi secara keseluruhan.
- **Left / Right & Up / Down**: Pengaturan posisi terperinci untuk menggeser arah sorotan.
