## 1. Membuka Wizard Penyiapan dan Memilih Shader

1. Tekan `N` di 3D Viewport untuk membuka bilah samping.
2. Buka tab **Character Setup Wizard**.
3. Pada menu tarik-turun **Game**, pilih **Zenless Zone Zero**.
4. Di **Setup Settings**, pilih **Shader** yang Anda inginkan:
   - **Kythera's Shader** (Disarankan): Shader anime modern yang mendukung preset Lighting Mode secara langsung, cahaya tepi, fake SSS, dan pengaturan warna pada panel Item.
   - **Legacy Shader**: Shader klasik ZZZ Setup File V2.0 dengan panel rig kontrol di 3D Viewport.

## 2. Mengimpor Karakter

Anda dapat menyiapkan model dengan satu klik menggunakan **Run Entire Setup**, atau langkah demi langkah melalui **Old Setup**.

1. *(Opsional)* Di **Setup Settings**, aktifkan **Hair & Clothes Physics** untuk menambahkan fisika dinamis pada rambut dan pakaian. Aktifkan **Disable Rigging** untuk melewati pembuatan rig dan hanya mengimpor material serta garis tepi.
2. Klik **Run Entire Setup** (atau **Set Up Character** pada Old Setup).
3. Jendela penelusuran berkas akan terbuka. Buka [folder karakter](/id/character-models/#zzz) yang berisi model `.fbx` dan tekstur.
4. Klik **Select Character Folder**.

## 3. Alur Penyiapan Otomatis

Saat penyiapan dijalankan, add-on melakukan langkah-langkah otomatis berikut untuk Zenless Zone Zero:

- **Set Up Character**: Mengimpor mesh `.fbx`, membersihkan vertex group, dan menstandarkan hierarki tulang.
- **Set Up Materials**: Mengganti material bawaan Blender dengan node **ZZZ Toon Shader** pilihan Anda dan menghubungkan tekstur diffuse, lightmap, bayangan mata, serta gradasi warna secara otomatis.
- **Set Up Outlines**: Menerapkan modifier garis tepi inverted-hull berbasis geometry node pada semua mesh karakter untuk menghasilkan garis yang tegas.
- **Fix Transformations**: Mereset transformasi lokasi, rotasi, dan skala.
- **Rig Character**: Mengintegrasikan **jideeh ZZZ Face Rig** khusus dan mengonfigurasi kontrol fisika dada/badan.
- **Finish Setup**: Mengganti Color Management ke **Standard** untuk menjaga akurasi warna asli tekstur.

## 4. Opsional: Menambahkan Material Bayangan Mata

Jika material bayangan mata perlu ditetapkan secara manual pada karakter:

1. Pilih mesh wajah karakter, lalu tekan `Tab` untuk masuk ke **Edit Mode**.
2. Arahkan kursor ke geometri bayangan mata, lalu tekan `L` untuk memilih komponen mesh bayangan mata.
3. Pada tab **Material Properties**, klik tombol `+` untuk membuat slot material baru.

<Image src={zzzEyeshadow1} alt="Memilih mesh bayangan mata dalam Edit Mode dan menambahkan slot material baru" loading="lazy" />

4. Pilih material **ZZZ Shader Eye** untuk slot yang baru dibuat.

<Image src={zzzEyeshadow2} alt="Menetapkan material ZZZ Shader Eye pada slot" loading="lazy" />

5. Klik tombol **Assign** untuk menerapkan material pada mesh bayangan mata yang dipilih.

<Image src={zzzEyeshadow3} alt="Mengklik tombol Assign untuk menerapkan material bayangan mata" loading="lazy" />
