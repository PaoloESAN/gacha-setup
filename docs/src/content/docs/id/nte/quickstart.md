# Panduan Penyiapan Neverness to Everness

Pelajari cara mengimpor model karakter `.ueformat` dari Neverness to Everness, menetapkan shader Omatsuri, dan mengonfigurasi node compositor pascapemrosesan.

## Langkah Singkat

1. Instal add-on **UEFormat** yang disertakan (ditangani secara otomatis oleh Gacha Setup).
2. Buka **Character Setup Wizard** (tombol <kbd>N</kbd>).
3. Pilih **Neverness to Everness**.
4. Klik **Import & Setup NTE Model**.

---

:::note[Konten Akan Ditambahkan]
Bagian ini akan berisi panduan singkat lengkap langkah demi langkah untuk menyiapkan karakter Neverness to Everness, mengatur node ketebalan garis tepi, dan membuat susunan node compositor.
:::
