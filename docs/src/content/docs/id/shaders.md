# Alur Kerja Shader dan Material

Gacha Setup secara otomatis menghubungkan dan mengonfigurasi shader anime khusus untuk alur kerja setiap mesin gim.

## Fitur

- **Pemetaan Tekstur Otomatis**: Peta Diffuse, Lightmap, Normal, dan Shadow dihubungkan secara otomatis.
- **Garis Tepi Inverted-Hull Kustom**: Penyesuaian ketebalan dan warna garis tepi secara presisi.
- **Perbaikan Bayangan Mata dan Wajah**: Node shader untuk mencegah bayangan yang tidak diinginkan pada mata.

---

:::note[Konten Akan Ditambahkan]
Bagian ini akan berisi penjelasan terperinci tentang node shader, penyesuaian gradasi warna, pengaturan kelompok cahaya, dan node compositor.
:::
