## Kamera Jideeh

### Cara Menggunakan

- **Sudut L kuning / AIM**: Dapat diskalakan. Kamera mengikuti widget ini untuk membidik. Mengubah skalanya akan menyesuaikan FOV.
- **Lingkaran oranye / FOCUS**: Mengatur kedalaman bidang, yaitu lokasi atau jarak fokus kamera.
- **Lingkaran ungu / PIVOT**: Mengatur pusat orbit kamera.
- **Garis kuning melengkung / FREQ**: Mengatur frekuensi guncangan.
- **Penggeser kuning vertikal / SHAKE_Y**: Mengatur intensitas guncangan pada sumbu Y.
- **Penggeser kuning horizontal / SHAKE_X**: Mengatur intensitas guncangan pada sumbu X.
- **Widget F / DOF**: Mengaktifkan atau menonaktifkan kedalaman bidang.
- **ROOT**: Pengontrol utama kamera.
- **CAM (di belakang kamera)**: Berfungsi sebagai penstabil kamera. Anda dapat memindahkan kamera tanpa mengubah arah bidikannya.

## Bayangan Rambut

:::caution[Eksperimental]
Fitur ini bersifat eksperimental dan dapat menghasilkan hasil yang tidak terduga.

**Hair Shadows tidak dapat digunakan bersamaan dengan See Eye Through.**
:::

Menambahkan bayangan rambut pada wajah karakter di Blender 5.2 atau yang lebih baru.

1. Dalam **Object Mode**, pilih mesh karakter atau armature-nya. Karakter harus memiliki material bernama Face dan Hair atau Bangs agar alat dapat mengenali wajah dan rambut.
2. Di **Gacha Setup → Utilities**, klik **Hair Shadows**.
3. Buka **Compositor** dan pilih grup **Hair Shadows** milik karakter. Sesuaikan **Offset X** dan **Offset Y** untuk posisi bayangan, **Shadow Tint** untuk warna, serta **Strength** untuk intensitasnya.

<Image src={hairShadowImg} alt="Grup compositor Hair Shadows dan efeknya pada wajah karakter" loading="lazy" />

Alat ini mengaktifkan compositor viewport secara otomatis. Periksa hasilnya dalam mode rendered shading atau hasil render. Jalankan kembali alat pada karakter yang sama untuk memperbarui efek yang sudah ada.

## Menerapkan Gerakan VMD

:::caution[MMD Tools Diperlukan]
Add-on **MMD Tools** harus terinstal di Blender untuk mengimpor gerakan VMD.
:::

1. Pilih armature karakter.
2. Klik **Gacha Setup → Utilities → Apply VMD Motion**, lalu pilih berkas `.vmd` Anda.

   <Image src={vmdMotionImg} alt="Pemilihan gerakan VMD dan opsi impor" loading="lazy" />

3. Sesuaikan opsi di pojok kanan atas jika perlu, lalu konfirmasikan dengan **Apply VMD Motion**.

:::caution
Proses ini dapat memerlukan waktu, terutama saat mengimpor ekspresi wajah. Tunggu hingga selesai.
:::
