# Panduan Instalasi

:::note[Kompatibilitas Blender]
**Blender 5.2 disarankan.** Gacha Setup juga kompatibel dengan **Blender/Goo Engine 4.1+**. Jika menggunakan Blender **di bawah versi 4.5**, instal **BetterFBX** untuk mengimpor model.
:::

## Langkah-Langkah Instalasi

1. Unduh paket rilis `Gacha_Setup-<version>.zip` terbaru dari GitHub Releases.
2. Jalankan Blender 5.2 (disarankan) atau Blender/Goo Engine 4.1+. Untuk Blender di bawah versi 4.5, instal BetterFBX terlebih dahulu.
3. Buka **Edit > Preferences > Add-ons**.
4. Klik menu tarik-turun di pojok kanan atas, lalu pilih **Install from Disk...**
5. Pilih berkas `.zip` yang telah diunduh, lalu centang add-on tersebut.
6. Tekan <kbd>N</kbd> di 3D Viewport untuk membuka panel bilah samping **Character Setup Wizard**.

---

## Dependensi yang Disertakan

Saat diaktifkan, add-on secara otomatis memeriksa dan menginstal dependensi tambahan yang diperlukan:

- **ExpyKit**: Mengotomatiskan konversi karakter Rigify.
- **UEFormat**: Memungkinkan impor langsung model Neverness to Everness (`.ueformat`).
