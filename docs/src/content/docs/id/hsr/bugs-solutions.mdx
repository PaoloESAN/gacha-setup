## Sparxie HoyoToon

Saat mengunduh aset model Sparxie dari **HoyoToon**, Anda mungkin mengalami masalah tekstur jika memilih varian **Elation**.

### Solusi

- Pastikan Anda menggunakan varian pakaian **Candy-Coated Waves**, bukan **Elation**.
- **Catatan**: Ini tidak mengubah model; hanya memperbaiki masalah tekstur.
