## 1. Membuka Wizard Penyiapan

1. Tekan `N` di 3D Viewport untuk membuka bilah samping.
2. Buka tab **Character Setup Wizard**.
3. Pada menu tarik-turun **Game**, pilih **Honkai: Star Rail**.

<Image src={hsrPanel} alt="Panel N wizard penyiapan Honkai: Star Rail" loading="eager" />

---

## 2. Mengimpor Karakter

Anda dapat menyiapkan model dengan satu klik menggunakan **Run Entire Setup**, atau langkah demi langkah melalui **Old Setup**.

1. *(Opsional)* Di **Setup Settings**, aktifkan **Hair & Clothes Physics** untuk menambahkan fisika dinamis pada rambut dan pakaian. Aktifkan **Disable Rigging** untuk melewati pembuatan rig dan hanya mengimpor material serta garis tepi.
2. Klik **Run Entire Setup** (atau **Set Up Character** pada Old Setup).
3. Jendela penelusuran berkas akan terbuka. Buka [folder karakter](/id/character-models/#hsr) yang berisi model `.fbx` dan tekstur (misalnya `Avatar_Girl_March7th.fbx`).
4. Klik **Select Character Folder**.

<Image src={hsrCharacter} alt="Memilih folder model karakter HSR di Blender File View" loading="lazy" />

---

## 3. Alur Penyiapan Otomatis

Saat penyiapan dijalankan, add-on melakukan langkah-langkah otomatis berikut:

- **Set Up Character**: Mengimpor mesh `.fbx`, membersihkan vertex group, dan menstandarkan hierarki tulang untuk Honkai: Star Rail.
- **Set Up Materials**: Mengganti material bawaan Blender dengan node **StellarToon Shader** khusus dan menghubungkan tekstur diffuse (`_fuse`), lightmap (`_map`), serta gradasi warna (`_amp`) secara otomatis.
- **Set Up Outlines**: Menerapkan modifier garis tepi inverted-hull berbasis geometry node pada semua mesh karakter untuk menghasilkan garis yang tegas.
- **Fix Transformations**: Mereset transformasi lokasi, rotasi, dan skala.
- **Rig Character**: Mengintegrasikan **Isaac Face Rig** dan mengatur driver sumbu Y mata agar pupil tidak bergeser saat berkedip atau menjalankan animasi shape key.
- **Finish Setup**: Mengganti Color Management ke **Standard** untuk menjaga akurasi warna asli tekstur.
