:::note[Blender Compatibility]
Gacha Setup is designed for **Blender 5.2+**. Older Blender versions or Goo Blender are not supported.
:::

## Installation Steps

1. Download the latest `Gacha_Setup-<version>.zip` from the [latest GitHub release](https://github.com/PaoloESAN/gacha-setup/releases/latest).
2. Launch **Blender 5.2+**.
3. Drag and drop the downloaded `.zip` file into the Blender window.
4. Enable the **Enable Add-on** checkbox and click **OK** to confirm.
5. If it doesn't install automatically, open **Edit > Preferences > Add-ons**, click **Install from Disk...**, select the `.zip`, and enable the add-on checkbox.

## Setup Character

1. Press `N` in the 3D Viewport to open the **Character Setup Wizard** sidebar panel.

<Image src={mainPanel} alt="Character Setup Wizard main panel (v3.7.1)" loading="eager" />

2. Select your game (Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Neverness to Everness, Wuthering Waves, Arknights: Endfield).
3. *(Optional)* Under **Setup Settings**, enable **Hair & Clothes Physics** to add dynamic physics to the hair and clothing when the character moves. Enable **Disable Rigging** to skip rig generation and import the character with materials and outlines only.

<video autoplay loop muted playsinline controls style="width: 100%; border-radius: var(--sl-border-radius-md, 8px); margin: 1rem 0;">
  <source src={physicsVideo} type="video/mp4" />
</video>

4. Click **Run Entire Setup** (or run the steps one by one under **Old Setup**).
5. Select your [character folder](/character-models/) and click **Select Character Folder**.

<Image src={selectCharacter} alt="Select Character Folder" loading="lazy" />

6. Wait a few seconds and your character will be ready in the scene.

<Image src={characterEscene} alt="Character ready in the scene (Setup completed successfully)" loading="lazy" />
