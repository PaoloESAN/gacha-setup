:::note[Blender Compatibility]
Gacha Setup is designed for **Blender 5.2+**. Older Blender versions or Goo Blender are not supported.
:::

## Installation Steps

1. Download the latest `Gacha_Setup-<version>.zip` from the [latest GitHub release](https://github.com/PaoloESAN/gacha-setup/releases/latest).
2. Launch **Blender 5.2+**.
3. Drag and drop the downloaded `.zip` file into the Blender window.
4. Enable the **Enable Add-on** checkbox and click **OK** to confirm.
5. If it doesn't install automatically, open **Edit > Preferences > Add-ons**, click **Install from Disk...**, select the `.zip`, and enable the add-on checkbox.

## Setup Character

1. Press `N` in the 3D Viewport to open the **Character Setup Wizard** sidebar panel.

<Image src={mainPanel} alt="Character Setup Wizard main panel" loading="eager" />

2. Select your game.
3. *(Optional)* Under **Setup Settings**, enable **Hair & Clothes Physics** to add dynamic physics to the hair and clothing when the character moves, and adjust the influence sliders if desired.

<video autoplay loop muted playsinline controls style="width: 100%; border-radius: var(--sl-border-radius-md, 8px); margin: 1rem 0;">
  <source src={physicsVideo} type="video/mp4" />
</video>

4. Click **Run Entire Setup** (or run the steps one by one under **Basic Setup**).
5. Select your [character folder](/character-models/) and click **Select Character Folder**.

<Image src={selectCharacter} alt="Select Character Folder" loading="lazy" />

6. Wait a few seconds and your character will be ready in the scene.

<Image src={characterEscene} alt="Character ready in the scene" loading="lazy" />

## Legend

<Image src={panelLegend} alt="Character Setup Wizard panel legend" loading="lazy" />

1. **Add-on Updater**: Allows checking for new add-on updates and enabling automatic background update checks.
2. **Game selector & Run Entire Setup**: Select your game (Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Neverness to Everness, Wuthering Waves) and click **Run Entire Setup** to execute the complete automated import, shaders, outlines, rigging, and compositing pipeline in one click.
3. **Setup Settings**: Optional settings before running setup. Enable **Hair & Clothes Physics** to generate dynamic Damped Track physics on the hair and clothing when the character moves, and calibrate the Hair and Clothes influence sliders.
4. **Basic Setup & Advanced Setup**: **Basic Setup** allows running each setup step individually from top to bottom. **Advanced Setup** provides low-level control for fine-tuning individual components (only for advanced users).
