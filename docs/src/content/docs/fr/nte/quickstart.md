# Guide de configuration Neverness to Everness

Apprenez à importer des modèles de personnages `.ueformat` de Neverness to Everness, à assigner les shaders Omatsuri et à configurer les nœuds de compositeur de post-traitement.

## Étapes rapides

1. Installez l'add-on intégré **UEFormat** (géré automatiquement par Gacha Setup).
2. Ouvrez **Character Setup Wizard** (touche <kbd>N</kbd>).
3. Sélectionnez **Neverness to Everness**.
4. Cliquez sur **Import & Setup NTE Model**.
