## 1. Ouvrir l'assistant de configuration

1. Appuyez sur `N` dans la vue 3D pour ouvrir la barre latérale.
2. Accédez à l'onglet **Character Setup Wizard**.
3. Dans le menu déroulant **Game**, sélectionnez **Arknights: Endfield**.

<Image src={akePanel} alt="Panneau N Setup Wizard d'Arknights: Endfield (v3.7.1)" loading="eager" />

---

## 2. Importer votre personnage

Vous pouvez configurer votre modèle en un clic avec **Run Entire Setup** ou étape par étape via **Old Setup**.

1. *(Optionnel)* Sous **Setup Settings**, activez **Hair & Clothes Physics** pour ajouter une physique dynamique aux cheveux et aux vêtements. Activez **Disable Rigging** pour ignorer la génération du rig et importer uniquement les matériaux + contours.
2. Cliquez sur **Run Entire Setup** (ou **Set Up Character** sous Old Setup).
3. Une fenêtre d'explorateur de fichiers apparaîtra. Accédez à votre [dossier de personnage](/fr/character-models/#ake---arknights-endfield) contenant le modèle `.fbx` (`chr_XXXX_name_uimodel.fbx`, par ex. `chr_0032_lizhiyan_uimodel.fbx`), le sous-dossier `Materials` et les textures.
4. Cliquez sur **Select Character Folder**.

<Image src={akeCharacter} alt="Vue fichier Blender sélectionnant le dossier du modèle de personnage Arknights: Endfield" loading="lazy" />

## 3. Pipeline de configuration automatisé

Lors de l'exécution de la configuration, l'add-on effectue les étapes automatisées suivantes pour Arknights: Endfield :

- **Set Up Character** : Importe le maillage `.fbx`, nettoie les groupes de vertex et standardise les hiérarchies d'os.
- **Set Up Materials** : Remplace les matériaux Blender par défaut par des nœuds de shader personnalisés **Arknights: Endfield PBRToon** (`Arknights: Endfield_PBRToonBase`, `BaseFace`, `BaseHair`), en associant les matériaux du corps, des vêtements, du visage, des cheveux, de l'iris et alpha.
- **Setup Outlines** : Applique des modificateurs de contour inverted-hull (`Dots Stroke`) à tous les maillages du personnage pour un rendu de tracé net.
- **Rig Character** : Configure l'armature Rigify, l'adaptation **Isaac Face Rig** pour Endfield et le système de pilotes de tête.
- **Setup Compositor Nodes** : Configure l'arbre de nœuds de composition pour le rendu en temps réel des ombres de la tête.
- **Finish Setup** : Passe Color Management sur **Standard** pour préserver la fidélité des couleurs brutes des textures.

## 4. Paramètres de Viewport Shading & Compositor

Pour afficher les shaders PBRToon et la composition d'ombres de la tête en temps réel dans la vue 3D :

1. Ouvrez le menu **Viewport Shading** (en haut à droite de la vue 3D).
2. Sous **Lighting**, activez **Scene Lights** et **Scene World**.
3. Sous **Compositor**, réglez le menu déroulant sur **Always** (ou **Camera**).
