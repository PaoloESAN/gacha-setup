## 1. Ouvrir l'assistant de configuration & Sélection du Shader

1. Appuyez sur `N` dans la vue 3D pour ouvrir la barre latérale.
2. Accédez à l'onglet **Character Setup Wizard**.
3. Dans le menu déroulant **Game**, sélectionnez **Zenless Zone Zero**.
4. Sous **Setup Settings**, sélectionnez votre **Shader** préféré :
   - **Kythera's Shader** (Recommandé) : Shader anime moderne prenant en charge les préréglages Lighting Mode en temps réel, la rim light, le faux SSS et les contrôles de teinte dans le panneau Item.
   - **Legacy Shader** : Shader classique ZZZ Setup File V2.0 avec panneaux de rig de contrôle dans la vue 3D.

## 2. Importer votre personnage

Vous pouvez configurer votre modèle en un clic avec **Run Entire Setup** ou étape par étape via **Old Setup**.

1. *(Optionnel)* Sous **Setup Settings**, activez **Hair & Clothes Physics** pour ajouter une physique dynamique aux cheveux et aux vêtements. Activez **Disable Rigging** pour ignorer la génération du rig et importer uniquement les matériaux + contours.
2. Cliquez sur **Run Entire Setup** (ou **Set Up Character** sous Old Setup).
3. Une fenêtre d'explorateur de fichiers apparaîtra. Accédez à votre [dossier de personnage](/fr/character-models/#zzz) contenant le modèle `.fbx` et les textures.
4. Cliquez sur **Select Character Folder**.

## 3. Pipeline de configuration automatisé

Lors de l'exécution de la configuration, l'add-on effectue les étapes automatisées suivantes pour Zenless Zone Zero :

- **Set Up Character** : Importe le maillage `.fbx`, nettoie les groupes de vertex et standardise les hiérarchies d'os.
- **Set Up Materials** : Remplace les matériaux Blender par défaut par les nœuds **ZZZ Toon Shader** de votre choix, en associant automatiquement les textures diffuse, lightmap, eyeshadow et color ramp.
- **Set Up Outlines** : Applique des modificateurs de contour inverted-hull par geometry-node à tous les maillages du personnage pour un rendu de tracé net.
- **Fix Transformations** : Réinitialise les transformations de position, rotation et échelle.
- **Rig Character** : Intègre le **jideeh ZZZ Face Rig** spécialisé et configure les contrôles physiques de la poitrine et du torse.
- **Finish Setup** : Passe Color Management sur **Standard** pour préserver la fidélité des couleurs brutes des textures.

## 4. Optionnel : Ajouter le matériau Eyeshadow

Si votre personnage nécessite une assignation manuelle du matériau d'ombre à paupières (eyeshadow) :

1. Sélectionnez le maillage du visage du personnage et appuyez sur `Tab` pour passer en **Edit Mode**.
2. Survolez la géométrie de l'eyeshadow et appuyez sur `L` pour sélectionner les composants du maillage de l'eyeshadow.
3. Dans l'onglet **Material Properties**, cliquez sur le bouton `+` pour créer un nouvel emplacement de matériau.

<Image src={zzzEyeshadow1} alt="Sélection du maillage eyeshadow en Edit Mode et ajout d'un nouvel emplacement de matériau" loading="lazy" />

4. Assignez le matériau **ZZZ Shader Eye** à l'emplacement nouvellement créé.

<Image src={zzzEyeshadow2} alt="Assignation du matériau ZZZ Shader Eye à l'emplacement" loading="lazy" />

5. Cliquez sur le bouton **Assign** pour appliquer le matériau au maillage eyeshadow sélectionné.

<Image src={zzzEyeshadow3} alt="Clic sur le bouton Assign pour appliquer le matériau eyeshadow" loading="lazy" />
