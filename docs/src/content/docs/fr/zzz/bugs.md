# ZZZ — Bugs et solutions

Guide détaillé pour diagnostiquer et corriger les problèmes courants avec les modèles de Zenless Zone Zero.

## Problèmes courants

### Problème 1 : Rotation de roulis du widget d'épaule inversée
- **Symptôme** : Les os de contrôle des épaules pivotent à l'envers lors du déplacement des bras.
- **Solution** : Utilisez l'outil **Correct Shoulder Roll** dans ZZZ Rig Utilities.

### Problème 2 : Décalage du contrôle parent de la cuisse
- **Symptôme** : Les maillages des jambes se détachent ou s'étirent anormalement lors de la flexion des hanches.
- **Solution** : Cliquez sur **Reposition Thigh Parents** dans le panneau N de l'add-on.
