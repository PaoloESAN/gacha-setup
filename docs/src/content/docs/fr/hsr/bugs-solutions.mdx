## Sparxie Hoyotoon

Lors du téléchargement des assets du modèle de Sparxie depuis **HoyoToon**, vous pouvez rencontrer des problèmes de textures si vous sélectionnez la variante **Elation**.

### Solution

- Assurez-vous d'utiliser la variante de tenue **Candy-Coated Waves** au lieu d'**Elation**.
- **Note** : Cela ne modifie en rien le modèle ; cela corrige uniquement les problèmes de textures.
