# Rigging Suite Overview

The **Gacha Setup** rigging module unifies bone hierarchy fixes, facial driver creation, bone collections, and Rigify generation across anime gacha models.

## Key Rigging Features

1. **Blender 5.2+ Bone Collections**:
   - Interactive N-panel **Rig Layers UI** with visibility toggles and solo star ($\star$) buttons.
   - Dynamic collection query preventing standard Blender 5.x armature script errors.

2. **Expy-Kit & Rigify Integration**:
   - One-click metarig alignment and Rigify controls generation.
   - Automatic re-parenting of clothing, accessories, and hair meshes.

3. **Facial Driver Pipeline**:
   - Eye tracking controls linked with Y-location drivers to avoid eye popping.
   - Expression shape keys linked to master facial bone gizmos.
