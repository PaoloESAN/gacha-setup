### Why is Goo Engine not supported?
Because it is a paid software and I do not want to encourage piracy. Everything in this addon will consist of 100% free resources, such as community shaders, addons, and utilities.

### Which Blender versions will be supported?
The most recent official releases, starting with **Blender 5.2+**, unless future updates introduce breaking issues that affect the addon.

### I want to join a 3D community specializing in this type of content.
Join the **[Omatsuri](https://discord.gg/omatsuri)** Discord server, where very talented people share work every day, or **[HoyoToon](https://discord.com/invite/hoyotoon)** if you need a similar addon for Unity.

### I want you to add a new game, what do you need?
I need a rigging script (optional, but makes implementation much easier), the shader (mandatory), and a raw repository to fetch the character models, textures, and assets.
