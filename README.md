# Genshin Setup Wizard (Blender 5.0+ Modified Version)

This is a modified version of the original **Setup Wizard** add-on, specifically updated and fixed to work seamlessly with **Blender 5**.

## What's New?
- **Blender 5 Compatibility**: Fixed various API changes, driver issues, and geometry nodes setups to ensure full compatibility with Blender 5.0 and newer versions.
- **Stable Rigging**: Addressed driver variable initialization errors, outline rendering bugs, and other rigging issues present in the original addon.

- **ZZZ Face Rig**: jideeh (on Discord) — Facial rig for Zenless Zone Zero characters

## Installation
1. In Blender, go to `Edit` > `Preferences` > `Add-ons`.
2. Click on the drop-down menu in the top right corner and select `Install from Disk...`.
3. Select the `.zip` file of this modified add-on.
4. Enable the add-on by checking the box next to it.
