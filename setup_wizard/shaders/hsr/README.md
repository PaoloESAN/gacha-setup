# Honkai: Star Rail Shader (StellarToon)

This folder contains the **StellarToon** shader files for setting up **Honkai: Star Rail** character models in Blender.

* **Original Repository**: [https://github.com/festivities/Blender-StellarToon](https://github.com/festivities/Blender-StellarToon)
* **Original Author**: [Festivity](https://github.com/festivities) ([YouTube](https://www.youtube.com/channel/UCXCTHNBA8TVs0s5aQuNtWwg) | [Twitter](https://x.com/festivizing))

---

## Included Shader Files

* `StellarToonV1.1.blend` — Main StellarToon shader nodes and materials setup for Honkai: Star Rail models.
